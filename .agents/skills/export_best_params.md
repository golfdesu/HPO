# Export Best Params Skill

Consolidates all individual `*_best_params.json` files generated by Optuna into a single unified JSON configuration ready for consumption by the benchmark models in `../model/`.

## Script Usage
```python
import glob, json

all_params = {}
for f in sorted(glob.glob("*_best_params.json")):
    with open(f, "r", encoding="utf-8") as jf:
        data = json.load(jf)
        model_name = data.get("model_name", f.replace("_best_params.json", ""))
        all_params[model_name] = data

with open("hpo_pytorch_best_params.json", "w", encoding="utf-8") as out:
    json.dump(all_params, out, indent=4)
print(f"Exported {len(all_params)} models to hpo_pytorch_best_params.json")
```
